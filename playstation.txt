	Project Title

Playstation Cafe Management System (Desktop Application)

1. Goal
Build modern offline-first desktop application using python and PyQT to manage playstation cafe with
	a. playstations
	b. multiple administration
	c. Time based sessions
	d. dynamic joystick addition or substraction during the game
	e. accurate pricing and financial tracking
	f. Daily weeekly monthly and custom reports to calculate income or outcome

2. Technology Stack
	Python
	GUI framework PyQT
	SQLite
	ORM SQLAlchemy
	Architecutere MVC

5. Session System
	5.1 Sessions
	A session represents the full gameplay period
	
		id
		playstation_is
		admin_id
		start_time
		end_time
		cash_price
		terminal_price
		total_price
		payment_type (cash, terminal, hybrid)
		
		(*friends may share the bill half of them pay cash some of them pay via terminal)
	
	5.2 Session Segements
		A session must be split into segments to handle real-world changes
		
		why? customers may
			* Add / Remove joysticks mid-game
		
		SessionSegment
			id
			session_id (fk)
			start_time
			end_time
			joystick_count
			ps_hour_price
			joystick_hour_price
			total_price
			
	5.3 Example Scenario
		Segment		Duration	Joystick	Total
		1		1 hour		2		15000
		2		1 hour		4		20000
	
	* When session start we will give 2 joystick for free when customers want extra joysticks we can add when customers add extra joysticks they only pay for extra joysticks
	
	5.4 Business Rule
		Start Session

		* Create session
		* Create first segment (may add extra joystick or not by default 2 joystick for free)
		* customers may open three type of situation
			* they may open for exact hour 1 2 1.5 2.5 etc
			* they may open for exact money like 15000 25000 45000 ect.
			* they may open for vip it means they play how much they want at the end just paid money
		
		Modify session (very important)
		
		when admin changes joystick count (add or remove)
			1. close current segment (set end_time)
			2. create new segment with updated joystick count (*again it if free for first 2 joystick we will give 2 joystick 
				for free every playtstaion by default will have 2 joysticks)
		
		End Session
			
		* Close active segments
		* calculate total from all segments
		* save payments with payment type
		
6. Joystick Management
	* calculate total available joysticks
	* On segment start
		* check availability
		* deduct used joysticks
	* On segment end
		* return joysticks to pool

8. Pricing Calculation
	segment_price = duration_hours * playstation_price + duration_hours * (joystick_count - 2) * joystick_price
	total_price = SUM(all segment prices)
